# Regional Product Sales Analysis | SQL & Power BI

## Project Overview

This project focuses on analyzing product sales data to understand overall business performance and identify patterns across different regions, products, customer types, payment methods, and time periods.

I used PostgreSQL to perform SQL-based analysis and Power BI to clean, transform, analyze, and visualize the data. The final outcome is an interactive dashboard presenting important sales KPIs and business performance.

The main objective was to explore sales trends, identify areas that need attention, and generate business insights that could support better decision-making.

## Tools & Technologies

- **PostgreSQL:** SQL queries, data analysis, aggregations, and KPI calculations.
- **Power BI:** Dashboard development and data visualization.
- **Power Query:** Data cleaning and transformation.
- **DAX:** Creating calculated measures and KPIs in Power BI.
- **GitHub:** Project documentation and version control.

## Project Objectives

- Analyze overall sales performance and revenue.
- Compare sales performance across different regions.
- Identify monthly revenue trends and fluctuations.
- Analyze order returns and return rates.
- Compare revenue generated by Retail and Wholesale customers.
- Understand revenue contribution across different payment methods.
- Identify the highest and lowest revenue-generating products.

## Project Workflow

### 1. Data Cleaning & Transformation

- Imported the sales dataset into Power BI.
- Used Power Query (Transform Data) to clean and prepare the dataset.
- Applied necessary transformations to make the data suitable for analysis.

### 2. SQL Analysis

Used PostgreSQL to explore the dataset and answer business-related questions.

The analysis covered:

- Overall sales performance and revenue.
- Regional sales comparisons.
- Monthly revenue trends.
- Order returns and return rates.
- Retail and Wholesale customer performance.
- Revenue by payment method.
- Product-wise sales performance.

**SQL Script:** [View SQL Analysis](sql/sales_kpi_analysis.sql)

### 3. KPI Development

Created six key performance indicators in Power BI using DAX measures:

| KPI | Description |
|---|---|
| Total Revenue | Total revenue generated from sales. |
| Total Orders | Total number of orders. |
| Total Quantity Sold | Total quantity of products sold. |
| Return Rate | Percentage of orders returned. |
| Average Order Value | Average revenue generated per order. |
| Revenue Growth Percentage | Revenue growth compared with the previous month. |

### 4. Dashboard Development

Developed an interactive Power BI dashboard to present the KPIs and explore sales performance through different visualizations.

The dashboard covers:

- Regional Sales Performance
- Monthly Revenue Trends
- Order Return Analysis
- Customer Type Analysis
- Payment Method Analysis
- Product Performance Analysis

## Key Business Insights

Some of the important findings from the analysis include:

- **Regional Performance:** North generated the highest revenue, while South recorded the lowest.
- **Monthly Revenue:** Average monthly revenue showed gradual improvement from 2023 to 2025.
- **Order Returns:** 24.8% of total orders were returned, making returns an important area for further investigation.
- **Customer Segments:** Retail and Wholesale customers contributed almost equally to total revenue.
- **Payment Methods:** Online payments generated the highest revenue, followed by Cash.
- **Product Performance:** Tablet generated the highest revenue, closely followed by Laptop and Printer.

For detailed observations and business recommendations, see [Business Insights](sql/business_insights.md).
